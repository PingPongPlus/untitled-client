# Keystrokes

- **Right Shift → HUD → Keystrokes** toggles the movement-key display.
- Its gear opens **glass**, **edges**, **mouse buttons**, and **space bar** toggles.
- Keys light up while held; labels and input follow your Minecraft keybindings.
- Glass uses the existing HUD material, global tint, and corner style. Disable glass for transparent labels.
- Menus, the HUD editor, pauses, and an unfocused game show idle keys.
- **G** opens the existing editor for dragging, resizing, and right-click reset.
- Keystrokes and edges start off; glass, mouse buttons, and the space bar start on. Saved preferences survive restarts and are included in **All off**.
- Options: `config/voicechat-keystrokes-hud.properties`; layout: `config/voicechat-hud-layout.properties`.
